## 4. 흐름별 메모 (문제 없었던 곳 포함)

- **요청 → 제안**: 보완 요청/답변 왕복, 제안 관심·보류·무관심 반응, 독점 기한 표기 모두 정상. 제안 카드의 가격 구간·수수료 포함 표시가 브랜드에게 충분히 읽힘.
- **샘플**: 입금 안내 → 신고 → 확인 → CN 출고(송장) → 검품 기록(사진) → 발송 → 피드백 → 회수 선택. 미회수 선택 시 상품가 청구가 발주 청구표에서 1회 차감되는 것까지 확인. CN 화면은 외부 의존 없이(규칙 9) 중국어로 동작.
- **발주**: 담기 조건(제안 관심 ∧ 샘플 피드백 관심) 강제 확인. 체인 순서 역행 불가. 재고 확보 수량 초과 입력 차단.
- **표준 패키지**: zip 구성(`products.csv`·`options.csv`·`images/`·`README.txt`), 원가·중국 원문 누출 0(`leaks`), 사진 JPG 변환.
- **보안 점검(브라우저, 브랜드 A 세션)**: `/admin`·`/admin/brands`·`/cn`·`/cn/products`·`/b/brand-b`·`/b/brand-b/orders` → 전부 404. 발주 상세 HTML에 `cost_cny`·`vendor_id`·`hidden_margin`·`fx_rate`·`_zh`·`weight_g` 없음. (전수 순회는 E2E `tests/e2e/security.spec.ts` 몫.)

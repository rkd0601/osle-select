# OSLE 표준 상품 패키지 규격 v1 (B-12)

결정(Jay, 2026-11-02): 쇼핑몰 관리자 양식을 그대로 따라가지 않고 **위아더 표준 패키지**를 만든다. 브랜드는 이 패키지를 받아 자기 쇼핑몰에 올린다(쇼핑몰별 컬럼 대응표는 README로 동봉). 쇼핑몰별 변형(cafe24·godo·imweb·smartstore)은 "미리 매핑된 참고 파일"로 남기되 `draft` 표시를 유지한다.

## 원칙
- 데이터는 **브랜드 뷰 컬럼만**(`v_products_brand` 등). 원가·원청·중량·중국어 원문·수수료·환율은 타입 단계에서 못 들어온다(`ExportProduct`).
- **판매가는 비운다. 공급가는 어떤 파일에도 넣지 않는다**(쇼핑몰에 공급가가 올라가는 사고 방지 — DECISIONS 9-3).
- 사진은 **위아더가 찍은 실물컷(`source='own'`)이면서 판매 사용 체크된 것**만, JPG로 변환(품질 90, 긴 변 2000px).
- 한 패키지 = 한 브랜드 × 선택 상품 N개. 파일명·코드는 노출 코드(`OS-26FW-0001`)만.
- 고정 문구(상세 HTML 표 제목 등)는 i18n 템플릿 키(규칙 10). 파일 안 텍스트는 한국어.

## 패키지 구조 (zip)
```
osle_package_{브랜드slug}_{YYYYMMDD}.zip
├─ README.txt                 사용법 + 쇼핑몰별 컬럼 대응표
├─ products.csv               상품 1행 (UTF-8 BOM, CRLF, RFC 4180, 수식 주입 방지)
├─ options.csv                컬러×사이즈 조합 1행 (SKU 제안 포함)
├─ sizes.csv                  사이즈별 실측 (부위별 컬럼)
├─ detail/{code}.html         상품 상세 HTML (혼용률·컬러·사이즈·세탁·원산지 표 + 실측표, 인라인 스타일만)
└─ images/{code}_{nn}.jpg     판매용 사진 (01 = 대표)
```

## options.csv 컬럼
`상품코드, 컬러, 사이즈, SKU 제안, 판매가(빈 칸), 재고수량(빈 칸)` — SKU 제안 = `{code}-{컬러영문 또는 번호}-{사이즈}` (예 `OS-26FW-0001-PINK-M`). 재고 수량은 저장하지 않는 원칙이라 빈 칸.

## sizes.csv 컬럼
`상품코드, 사이즈, 총장, 어깨, 가슴, 소매, 허리, 엉덩이, 밑위, 허벅지, 밑단, 출처`(12열, 코드 `lib/exports/osle.ts` 기준) — 카테고리 템플릿(`lib/codes.ts` 실측 부위)에 있는 부위만 채우고 나머지 빈 칸. 출처 = `위아더 실측` / `원청 사이즈표`.

## README.txt 내용
1. 패키지 설명 3줄(위아더가 직접 확인한 상품, 판매가는 직접 입력, 공급가는 플랫폼에서 확인).
2. 쇼핑몰별 컬럼 대응표(초안 — 각 쇼핑몰 양식은 Jay 확인 후 갱신):
   - 카페24: 상품명←상품명, 자체상품코드←상품코드, 판매가←판매가(입력), 상품 상세설명←상세 HTML(인라인), 옵션←컬러/사이즈(조합형), 상품 이미지←대표·추가 이미지
   - 고도몰: 상품명, 상품코드, 판매가, 상세설명, 옵션(컬러/사이즈), 이미지
   - 아임웹: 상품명, 상품코드, 가격, 본문, 옵션, 이미지
   - 스마트스토어: 상품명, 판매자 상품코드, 판매가, 상세설명, 옵션(조합형), 대표/추가 이미지
3. 사진 사용 범위(위아더 실물컷, 판매 목적 사용 허용, 재배포 금지).

## 구현 메모(개발)
- `lib/exports/osle.ts`가 표준 패키지(`products.csv`·`options.csv`·`sizes.csv`·README). 기존 `cafe24|godo|imweb|smartstore`는 `lib/exports/presets/`로 옮기고 `version: draft` 유지, B-12에서 "참고용(초안)" 라벨.
- B-12 기본 선택 = 표준 패키지. 쇼핑몰 변형은 체크박스로 추가 생성.
- 이미지 JPG 변환은 `sharp`(DECISIONS 9-6). 변환 실패 사진은 패키지에서 제외하고 README 끝에 목록.
- 테스트: 컬럼 순서·헤더 스냅샷, SKU 제안 규칙, 실측표 부위 매핑, 금지 키 스캔, CSV 주입 방지(기존).

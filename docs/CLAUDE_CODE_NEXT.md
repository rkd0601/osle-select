- T1 **샘플 상세의 행동이 여섯 개**(관심·보류·거절 · 운송장 · 회수 신청 · 미회수 · 발주 담기) — 피드백이 끝난 뒤엔 회수만 남긴다: `.nowblock` "샘플을 돌려보내 주세요" → **둘 중 하나**(`.choice`: "돌려보낼게요" + 운송장 입력 / "갖고 있을게요 (미회수)" + 상품가 안내) → "회수 신청" 버튼 하나. 피드백은 사실 줄("내 피드백 · 관심 · 발주서에 담김"). 프로토타입 "샘플 상세". 발주 담기는 진행 화면 카드/발주서 작성에서.

- T3 요청 상세 "항목 취소" 링크가 항목 아래 떠 있어 어느 항목인지 모호 → 항목 행 오른쪽 끝 "취소"(13 muted).
- T4 **제안 상세 대표 사진이 CN 정렬 1번이 아니다** — 편집 화면 1번은 핑크 정면인데 브랜드 제안 상세는 뒷면을 크게 보여 준다(홈 카드는 정면). `offers/[id]`가 `sort_order` 없이 첫 행을 쓰는 듯 — 전 화면 cover = `sort_order` 1번(실拍 우선). 썸네일 5장도 같은 순서.
- T5 청구 "쇼핑몰용 상품 파일"이 같은 이름으로 9건 — 상품별 **최신 1건**만 보이고 "이전 파일 n"으로 접기.
- T6 제안 상세 색상 점이 빈 원(색상 hex 없음) → hex 없으면 점 대신 이름만.
- T7 홈 "진행 중" 카드 제목 "2차 점검 — 울 니트 가디건 (오버핏)" — 요청명 접두어 빼고 항목 이름만(요청명은 진행 묶음 머리에 있다).

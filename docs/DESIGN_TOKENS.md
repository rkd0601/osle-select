# 디자인 토큰 — 디자인 라운드 준비 (PRD D19 · Figma 04 Design Direction)

13단계. Jay 디자인 라운드에서 **값만 바꾸면 화면 전체가 따라오도록** 토큰을 한 곳(`app/globals.css` `:root`)에 모았다. 이 문서는 현재 값·사용 횟수·바꿀 후보·Figma 매핑 칸이다. 숫자는 2026-11-02 기준 `app`·`components`의 클래스 사용 횟수.

> **2026-11-04 1차 패스 적용됨**(STEP14 §9): Jay 무드 레퍼런스(콘크리트 갤러리 매장 + 네이비 봉투·금박 모노그램)로 값을 바꿨다 — paper `#efefed`, ink `#17181c`, signature 네이비 `#1f2c4e`, 새 토큰 `--charcoal`·`--gold #b0915a`·`--gold-soft`·`--line-strong`, radius 2px, 본문 14px. 아래 표의 "현재 값"은 1차 패스 이전 기록이다. Figma 라운드에서 다시 이 자리의 값만 바꾼다.

바꾸는 법: `:root`의 `--*` 값만 고친다. Tailwind 유틸 이름(`text-ink-2`, `text-body` …)은 그대로 둔다 — 화면 코드는 손대지 않는다.

## 2. 타입 스케일 — 17단계 → 9단계 (DECISIONS 11-2)

유틸 이름은 그대로 두고 `:root --fs-*` 값만 합친다(예: `--fs-strong: 16px` = `--fs-h5`). 화면 코드 변경 0.

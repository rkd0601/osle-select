# 화면 테스트 안내 (2026-11-04)

실제 화면을 눌러 보며 확인하는 방법이다. 데이터는 개발자가 만든 **클라우드 개발 DB**(시드 데이터)를 쓴다 — 개발자와 같은 DB를 쓰므로 바꾼 내용은 그대로 남는다. 운영 데이터가 아니니 마음껏 눌러도 된다.

## 1. 켜기
- Claude Code 앱의 브라우저 창에 이미 열려 있으면 그대로 쓰면 된다.
- 직접 켤 때: `scripts\start-dev.cmd` 더블클릭 → 검은 창이 뜨고 8초쯤 뒤 브라우저가 `http://localhost:3000/login`을 연다. 끌 때는 검은 창을 닫는다.
- 같은 와이파이의 휴대폰에서 볼 때: 검은 창의 `Network:` 주소(예: `http://10.x.x.x:3000`)를 휴대폰 브라우저에 입력. 회사 방화벽이 막으면 안 열릴 수 있다.

## 2. 로그인 — "개발용 빠른 로그인"
로그인 화면 아래쪽 **개발용 빠른 로그인** 버튼을 누르면 그 역할로 바로 들어간다(비밀번호 입력 없음). 내 컴퓨터 개발 서버에서만 보이고, 실제 배포 화면에는 나오지 않는다. 다른 역할로 바꾸려면 **로그아웃**(브랜드 화면은 오른쪽 위, 관리자는 왼쪽 메뉴 아래) → 다른 버튼. 로그인 화면으로 바로 가서 다른 버튼을 눌러도 바뀐다.

| 버튼 | 처음 화면 | 언어 |
|---|---|---|
| 브랜드 A 대표 (오슬 · 김대표) | `/b/osle` 브랜드 홈 | 한국어 |
| 브랜드 A 직원 (박MD) — 구매 권한 없음 | 같은 브랜드, 발주 확정 버튼이 막혀 있어야 함 | 한국어 |
| 브랜드 B 대표 | `/b/brand-b` (요청·제안 없음) | 한국어 |
| 위아더 관리자 | `/admin` 대시보드 | 한국어 |
| 중국 소싱 담당 (王小姐) | `/cn` | 중국어 |
| 원청 사장 (中洲 3F-312) | `/cn` — 자기 원청 상품만 | 중국어 |

## 3. 시드에 들어 있는 것
- 브랜드 A의 요청 1건 "에코퍼 F/W" — 항목 2개(에코퍼 크롭 자켓, 롱 코트), 중국 담당 王小姐 배정.
- 상품 3개: 에코퍼 크롭 카라 자켓(브랜드 A에 **제안 발행됨**), 에코퍼 롱 코트(검수 완료 — 발행 대기), 숏 무스탕(검수 대기).

## 4. 따라 해 볼 흐름 (PRD 화면 ID)

**A. 브랜드가 요청하고 제안을 받는다**
1. 브랜드 A 대표 → 홈(B-01) "지금 당신 차례"에 새 제안 1건.
2. 요청 → **상품 요청하기**(B-02): 사진 또는 링크 1개 + 한 줄 설명, 항목 추가. 제출 → 요청 목록(B-03)에 생김.
3. 제안(B-04) → 에코퍼 크롭 카라 자켓 라인시트 → 상품 상세(B-05). 원가·원청·중국어 원문이 **어디에도 없어야** 한다.
4. 관심 표시 → 샘플(B-06) → 컬러×사이즈별 수량 입력 → 샘플 요청서 제출.

**B. 위아더가 받아서 처리한다**
1. 위아더 관리자 → 대시보드(A-01): 오늘 할 일이 지연 순으로.
2. 요청 접수·배정(A-02): 방금 브랜드가 올린 요청 → 항목 정리, 중국 담당 배정.
3. 상품 검수(A-03): 숏 무스탕 → 공개 조건(사진·혼용률·사이즈표·중량 등)이 모자라 승인 버튼이 막혀 있어야 정상. 반려 사유 템플릿으로 반려해 보기.
4. 제안 발행(A-04): 에코퍼 롱 코트 → 브랜드 A 항목 2(롱 코트)에 발행 → 브랜드 A 제안 목록에 새로 뜨는지 확인.
5. 샘플 관리(A-05): 브랜드가 낸 샘플 요청서 → 물류비·입금 확인 → 검품 → 회수.
6. 발주 관리(A-06): 재고 확인 → 선금 → 견적 → 최종 견적 → **브랜드 동의** → 확정 순서. 최종 견적 뒤에는 브랜드가 발주서 화면에서 **"₩… 이 금액으로 진행"**을 눌러야 관리자 화면에 "발주 확정" 버튼이 나온다(브랜드 동의 대기 문구 → 동의 시각·금액). 순서를 건너뛰는 버튼은 나오지 않아야 한다.
   - 지금 개발 DB에 브랜드가 동의까지 마친 발주서 1건(오슬, ₩746,550)이 있다 — 관리자로 들어가 "발주 확정"을 눌러 보면 된다.

**C. 중국에서 상품을 올린다** (중국어 화면)
1. 중국 소싱 담당 → 내 요청 항목(C-01) → 상품 추가 → 모바일 등록(C-02): 사진 1장 + 원가 + 원청.
2. PC 상세(C-03): 공개 조건 체크리스트가 다 채워져야 검수 요청 버튼이 켜진다.
3. 원청 사장으로 바꿔 들어가면 가격 칸 이름이 "单价 ¥"(공급 단가)이고, 다른 원청 상품은 보이지 않아야 한다. 소싱 담당이 대신 등록한 우리 가게 상품은 "代为登记 · 只读"로 보이고, 열어도 고칠 수 없어야 한다.

**D. 보안 확인**
- 브랜드 B 대표로 들어가서 주소창에 `localhost:3000/b/osle` 입력 → **404**(없는 페이지)가 나와야 한다. 브랜드 A 요청 주소를 그대로 붙여넣어도 404.
- 브랜드 화면에서 마우스 오른쪽 → 페이지 소스 보기 → `원가`·`cost`·`vendor`가 없어야 한다.
